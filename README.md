# 汪汪中文

香港小學中文 **筆順描紅** App。狗狗陪讀，每日 3 個字。

> 同小狗一齊寫好每個字；寫完可以再描，唔催命。

## 定位

| 項目 | 內容 |
|------|------|
| 對象 | 香港小學生（優先小一至小三） |
| 主課 | 繁體字形、筆順、**描紅** |
| 每日 | **3 個中文字** |
| 吉祥物 | 狗（數量、版面排序對齊英文 app **lazycat-english**） |
| 視覺 | 背景與風格**刻意不同**於懶貓英文 |
| 壓力 | 無愛心／無扣命；描錯可再試 |
| 評分文案 | 待定 |
