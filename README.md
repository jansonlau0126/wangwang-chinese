## 1. 主題與結構確認

**主題**：汪汪探險隊  
毛毛帶領一班狗狗朋友組成探險隊，從公園出發，去城市、大自然、家庭同學校探險，最後帶住新知識同新朋友返屋企。

**結構**：
- 共 60 日（15 週）
- 每日 3 個字
- 每寫完 4 日解鎖一隻新狗狗隊友（共 15 隻）
- 全部使用粵拼（Jyutping）
- 優先選筆順清晰、常用、適合幼小銜接／小一程度嘅字

## 3. 每日故事驅動策略（已確認）

採用 **輕量化故事驅動（A + B 混合）**：

- **每4日一組故事**：解鎖新隊友時，出一段完整小故事 + 1–2 張插圖。
- **其餘日子**：使用模板對話 + 表情變化（幾乎零插圖成本）。

優點：既有「每日有故事」感覺，又大幅降低插圖工作量。

### 故事示例（第1日）

**對話**：  
毛毛（戴住探險帽）：「汪！今日我哋正式組成『汪汪探險隊』啦！第一站……跑出去！」  
新隊友小黃（興奮跳）：「跳得高啲先至似探險家呀！」  
毛毛：「笑住出發最開心！寫完『跑、跳、笑』，我哋就正式啟程！」

**插圖方向**：  
- 柔和粉彩色系 + 清晰輪廓  
- 公園草地出發，陽光、白雲  
- 狗狗戴探險帽、小背包  
- 表情生動（自信、興奮、好奇）
