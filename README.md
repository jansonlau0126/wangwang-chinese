## 1. 主題與結構確認

**主題**：汪汪探險隊  
毛毛帶領一班狗狗朋友組成探險隊，從公園出發，去城市、大自然、家庭同學校探險，最後帶住新知識同新朋友返屋企。

**結構**：
- 共 60 日（15 週）
- 每日 3 個字
- 每寫完 4 日解鎖一隻新狗狗隊友（共 15 隻）
- 全部使用粵拼（Jyutping）
