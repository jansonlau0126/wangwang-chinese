Synthetic short SFX for 汪汪中文 (no third-party samples, no cloud TTS).

Files (mp3, ~0.2–0.4s each):
  complete.mp3 — day / warmup finished
  bone.mp3     — earned a bone
  unlock.mp3   — new dog / pose / ball unlock
  streak.mp3   — reserved for streak sticker (optional)

Generated with a local sine-tone script + ffmpeg; public-domain style original tones.
Toggle: 「我」頁「音效」；localStorage key ww-sfx-on (default on).
Reading still uses device speechSynthesis only — see ../audio/README.txt and docs/CANTONESE.md.
