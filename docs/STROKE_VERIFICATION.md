# 第一期筆順核對（2026-10-06）

第一期 30 字的筆畫幾何用 [hanzi-writer-data 2.0.1](https://github.com/chanind/hanzi-writer-data)（文鼎公眾授權條款）。次序以教育局《香港小學學習字詞表》網上筆順動畫為對照標準。教育局動畫檔只留在開發機，沒有放進這個 repo，App 亦不會載入教育局網址。

## 做法

1. 由字詞表結果頁找到每個字的 `stkdemo` 動畫。
2. 由動畫時間軸抽出每一筆黑色生長形狀：第一個 `setTransform` 當起筆位置，最後一個當整筆中心。按出現幀排序。
3. 把 hanzi-writer-data 的中線起點、終點翻成由上而下，同教育局起終點做全部排列，揀 `起點距離 + 0.35 × 終點距離` 最小的配對。
4. 用兩邊生長向量的點積睇方向。點積是負數先考慮把該筆中線反轉。

重排寫在 `data/stroke-overrides.json`。`order` 是 hanzi-writer-data **原本**筆畫的 1-based 序，按香港次序排出。`npm run strokes` 會產生 `data/strokes/U+XXXX.json`，並附上 `data/ARPHICPL.TXT`。

## 結果

30 字筆畫數目全部吻合。最佳配對的次序：

| 字 | 配對 | 處理 |
|----|------|------|
| 一 二 十 人 入 八 七 力 刀 三 大 小 山 口 土 上 下 女 日 月 木 水 火 天 手 中 牛 生 白 | 與 hanzi-writer-data 相同 | 不用改 |
| 出 | 原本第 3、1、2、4、5 筆 | 已重排 |

「出」的香港次序（對過 stkdemo 0321）：

1. 中間長直，由上向下
2. 左上直然後中橫
3. 右上直，由上向下
4. 左下直然後底橫
5. 右下直，由上向下

身份配對（不重排）的分數明顯差過 `3,1,2,4,5`。其餘 29 字的最佳配對都是原本次序。

## 未能完全確定

沒有一字完全對唔到次序。以下短筆的生長向量很短，點積接近 0，**方向**未能肯定，所以沒有加 `reverse`（反轉中線唔會反轉 SVG 外框，第一期亦未使用）：

| 字 | 說明 |
|----|------|
| 火 | 最短一筆點積約 0.012 |
| 上 | 約 0.024 |
| 月 | 第 3、4 筆約 0.028；`1243` 同 `1234` 分數好接近，但最佳仍是原次序，所以沒有重排 |
| 下 | 約 0.030 |
| 水 | 約 0.035 |

最佳配對上的點積都不是負數。若日後對實物抄寫確認要反轉，在 `data/stroke-overrides.json` 的 `reverse` 寫上重排後的 1-based 筆號，再跑 `npm run strokes`。
