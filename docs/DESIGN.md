# 視覺及互動設計

> 風格：**練習簿紙**——乾淨、文具柔和色、冷調白紙；淡色範字＋深色墨筆。**刻意不用米黃／cream**（與 lazycat-english 區分）。
> 對比度以 WCAG 2.x 公式用腳本計算（2026-10-05）。

## 1. 色板

| 角色 | Hex | 用途 | 對比（對紙 #F4F8FB） |
|------|-----|------|---------------------|
| 紙 Paper | `#F4F8FB` | 背景（冷調淡藍白，似練習簿） | — |
| 卡片 Surface | `#FFFFFF` | 描紅格、卡片 | — |
| 田字格線 Grid | `#9FC9B4` | 外框實線；中線用同色虛線（或 60% 透明） | 1.71（裝飾，非文字） |
| 淡範字 Model | `#CBD5DF` | 描紅底字（由筆畫資料畫出） | 1.39（刻意淡，非文字） |
| 墨筆 Ink | `#1B2533` | 小朋友寫的筆畫、動畫筆畫 | 14.47 ✅ |
| 主色 Accent | `#2F6FB0` | 按鈕、連結、進度 | 4.89 ✅ AA；白字在其上 5.22 ✅ |
| 成功 Success | `#2E7D52` | 完成一筆／一字、剔號 | 4.71 ✅ AA；白字在其上 5.03 ✅ |
| 溫和提示 Hint | `#E8A23A` | 提示筆畫閃動、起筆圓點、箭頭（**取代刺眼紅色**） | 2.04（只作圖形，不作文字） |
| 提示文字 Hint text | `#9A5A12` | 「先寫呢一筆」等提示字 | 5.11 ✅ AA |
| 主文字 Text | `#1F2A37` | 內文、標題 | 13.61 ✅ AAA |
| 次文字 Text-2 | `#4B5A6B` | 粵拼、說明 | 6.61 ✅ AA |

規則：
- 全 App **不用紅色表示錯誤**；錯筆只是不畫上去，用 Hint 色閃出正確筆畫。
- 非文字元素（格線、範字、提示圖形）不需 4.5:1；但提示圖形旁邊一定配 Hint text 或圖示。
- 田字格傳統綠線取柔和綠，與主色藍、提示橙清楚分開。

## 2. 字體
| 用途 | 字體 | 說明 |
|------|------|------|
| 介面文字 | 系統字體：`"PingFang HK", "Noto Sans HK", "Microsoft JhengHei", system-ui, sans-serif` | 不另載字型（Noto Sans HK 為 OFL，如要嵌入可用） |
| 字卡、今日列表、例詞 | **自由香港楷書 Free HK Kai**（CC BY 4.0，按香港《常用字字形表》） | 與 [STROKE_ORDER.md](./STROKE_ORDER.md) §6 一致；按字表子集化；「關於」頁署名 |
| 描紅區底字 | **不用字型**，由筆畫資料（hanzi-writer）畫出 | 確保與可描筆畫完全重疊 |
| 粵拼 | 介面字體，數字聲調不上標，Text-2 色 | |

字級：描紅格佔畫面短邊約 70%；介面最小 18px（小一閱讀）；按鈕觸控區 ≥ 48×48px。

## 3. 小狗解鎖規則
- 起始狗 **01 毛毛**（玩具貴賓），首頁 hero：毛毛伏喺空白田字格簿上瞓覺。
- **每完成 4 日解鎖一隻新狗**：`unlockedDogCount = min(15, 1 + floor(completedDays / 4))`；第 56 個完成日解鎖齊 15 隻。
- 「完成日」= 當日 3 字都完成「我自己寫」一次；**不需連續**、無斷 streak 懲罰、無生命值、無扣分。
- 每隻狗 7 張相：解鎖時顯示 happy；平日 sit／stretch／act-a／act-b 作陪讀；完成一字顯示 happy；休息顯示 sleep。
- **隱藏波波相**（綠色網球）：**固定規則，唔係隨機**——(1) 當日 3 字提示總數為 0，或 (2) 同一隻狗陪讀完成日數為 3 的倍數；每隻狗最多一張。重試階段**不會**清零當日提示次數。收集到放入「狗狗相簿」。
- 可隨時揀已解鎖的狗陪讀。

## 4. 每字流程
| 步（內部 id） | 畫面文案 | 描紅設定（見 STROKE_ORDER.md §5） |
|----|------|-----------------------------------|
| 1 listen | **汪汪讀** | 播單字＋例詞；可再聽 |
| 2 watch | **睇汪汪寫** | 筆順動畫；可慢啲／再睇 |
| 3 guided | **跟腳印描** | 淡範字＋起筆圓點／箭頭；`leniency 1.3`、錯 1 次提示 |
| 4 light | **少啲腳印** | 範字更淡、無箭頭；錯 2 次提示 |
| 5 free | **我自己寫** | 無範字；錯 3 次自動補筆 |
| 6 cheer | **攞骨頭** | 狗 happy 相；3 字完成後計一個完成日 |

- 每步可「再嚟一次」，不強制重做；提示次數只作家長報告，重試唔會清零。
- 墨筆用 Ink 色、筆寬約格寬 6%；正確一筆短暫轉 Success 色後回 Ink。
- 底部導航：首頁／進度／生字卡／狗狗／我。生字卡按週（15 字）瀏覽，已解鎖字可放大聽讀音同「再寫一次」（溫習唔推進日數）。
