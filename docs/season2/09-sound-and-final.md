# 聲音同完季動畫（已決定）

## 1. 讀音 → **裝置 TTS + 永遠顯示粵拼**

**已決定（2026-10-06）**：

| 項目 | 決定 |
|------|------|
| 方案 | 只用瀏覽器 `speechSynthesis` 粵語（香港）聲 |
| 錄音／寄送 mp3／雲 TTS | **不做** |
| 無粵語聲 | 唔播、唔改用普通話；提示睇粵拼；「我」頁有加聲說明 |
| 單字聲調 | 先例詞、後單字；粵拼為準 |
| SFX | 可用合成短音（可關）；同讀音方案分開 |

實作細節見 [`docs/CANTONESE.md`](../CANTONESE.md)。
