# 聲音同完季動畫（已決定方向）

## 1. 讀音 → **待定（不用人手錄音）**

**已決定（2026-10-06）**：唔要求用户或作者用麥克風錄音；亦唔要求用户自行開雲端 TTS 帳號。

| 項目 | 現況／方向 |
|------|------------|
| 而家 App | 裝置 `speechSynthesis`（優先 zh-HK／粵語聲）；無聲就顯示粵拼 |
| 預產檔名（不變） | `assets/audio/U+XXXX.mp3`、`U+XXXX_word.mp3` + `data/audio-manifest.json` |
| 點樣批量做出正確聲調嘅檔 | **方案研究中**（開源模型預生成、開放音節錄音、改良裝置 TTS 等）；要可公開分發、盡量少署名 |
| 雲端商業 TTS（Azure 等） | 用户唔想為呢個開帳；暫非首選 |
| 人手錄音／自錄 | **不做** |

研究結論同試聽樣本應寫返呢度或 `docs/CANTONESE.md`，先至開始大批產檔。

## 2. 音效（SFX）

可用 **合成／程式產生** 嘅極短音（唔使錄音室），全部可關：

| 時機 | 建議 | 優先 |
|------|------|------|
| 完成當日／攞骨頭 | 短「叮」 | ★★★★★ |
| 章節開放 | 輕快短音 | ★★★★ |
| 寫錯／再嚟 | 溫柔提示 | ★★★ |

商業音效庫若要署名 → 寧願自製合成或唔做。

## 3. 完季短動畫

同前：10–15 秒或靜態卡；用現有狗相；文案「汪汪探險隊（第二季）完成！」；按鈕返溫習／狗狗／分享。
