# 毛毛表情立繪（Momo Expressions）

這裡存放汪汪探險隊主角「毛毛」的多表情立繪，供 App 各處使用。

## 已準備的檔案（請手動上傳或從對話下載）

| 檔名 | 表情 | 主要用途 |
|------|------|----------|
| 01-default-happy.png | 預設開心（戴帽+背包） | 首頁、一般對話 |
| 02-encourage.png | 加油鼓勵（豎拇指） | 鼓勵小朋友繼續 |
| 03-celebrate.png | 慶祝（雙手舉高） | 完成任務、解鎖 |
| 04-thinking.png | 思考／好奇 | 引導、提問 |
| 05-comfort.png | 溫柔安慰 | 安慰、支持 |
| 06-ready.png | 出發／準備好 | 開始每日任務 |
| 07-surprised.png | 驚訝／哇 | 解鎖新狗狗、驚喜 |

## 上傳方式建議

因為圖片檔案較大，目前透過工具直接推送二進位檔有限制。  
請用以下任一方式上傳：

1. GitHub 網頁直接 Drag & Drop 到 `images/momo-expressions/` 資料夾
2. 使用 GitHub Desktop 或本機 git 推送
3. 之後再補「睡覺」與「得意」兩張（如需要）

## 風格統一要求
- 淺杏色捲毛玩具貴賓
- 藍色探險帽
- 柔和粉彩色系、清晰輪廓
- 白底，方便裁切使用
