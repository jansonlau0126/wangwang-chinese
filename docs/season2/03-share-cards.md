# 分享卡片定稿（Season 2）

> 狀態：**定稿**（2026-10-07）  
> 對齊：D4 唔做家庭／親子卡；D5 連寫只獎唔罰；D7 現有狗相 + 公園風底板 + DOM／canvas 出圖。

用短、暖嘅書面粵語；生字用楷書顯示；UI 字用粉圓風格。  
主視覺優先用 **S1 現有狗相**（寫實風草稿）。

---

## 1. 卡片類型一覽

| 類型 | 觸發 | 用途 |
|------|------|------|
| 每日完成卡 | 完成當日 3 字課堂 | 日常打卡 |
| 每週完成卡 | 完成 5 個課堂日 | 階段慶祝 |
| 章節卡 | 每約 4 日故事解鎖 | 收集炫耀 |
| 大階段卡 | 完成城市／自然／家庭／學校段 | 里程碑 |
| 連寫卡 | 連續課堂日達 3／7／14（只獎） | 鼓勵堅持 |
| 完季卡 | S2 第 60 日完成 | 完季 |

**不做**：親子卡、家庭邀請卡、家長報告卡。

## 4. 視覺規格（給實作）

| 項目 | 規格 |
|------|------|
| 底板 | 天空藍 `#C8EFFF` + 草地；可按大階段微調（城市偏灰藍、自然偏綠、家庭偏暖黃、學校偏淺紫） |
| 主圖 | 同伴狗 `sit`／`happy`（`assets/dogs/` 或 `assets/poses/`） |
| 生字 | 三個大楷字（Free HK Kai）+ 粵拼細字 |
| 裝飾 | 爪印、小骨頭（克制，唔遮字） |
| 出圖方式 | DOM／canvas 程式出圖（D7）；唔依賴未授權字型包 |
| 尺寸建議 | 1080×1350（IG 直式）或 1080×1080（正方形）可配置 |

---

## 5. 實作備註

1. 每日卡、章節卡最優先做 MVP。  
2. 大階段卡同完季卡可第二批。  
3. 連寫卡視 D5 貼紙／動畫一齊上。  
4. 所有卡唔出現「家長」「家庭邀請」「雙人進度」等字眼。  
5. 舊檔 `03-share-cards-detailed.md` 只係轉址，以本檔為準。
