# 家庭模式詳細規則

## 1. 開啟方式
- 喺「我」頁面點「開啟家庭模式」
- 生成邀請碼或連結，家長用另一個裝置加入
- 或者同一個裝置切換「小朋友帳號／家長帳號」

## 2. 核心功能

| 功能 | 說明 |
|------|------|
| 進度共用 | 小朋友寫字進度雙方都睇到 |
| 共同骨頭 | 獲得嘅骨頭放入家庭共同錢包 |
| 親子挑戰 | 每週額外一個簡單親子任務（例如一齊讀三次生字） |
| 專屬分享卡片 | 帶「親子」標記嘅卡片 |
| 家長鼓勵留言 | 家長可以留一句短鼓勵，小朋友睇到 |

## 3. 親子挑戰例子
- 「今日三個字，爸爸／媽媽同你一齊讀三次」
- 「一齊指住生字卡講出讀音」
- 「寫完之後，講一句用呢個字嘅說話」

完成親子挑戰 → 額外 +3 骨頭（家庭共用）

## 4. 權限同隱私
- 家長可以睇進度同歷史，但唔能直接改小朋友嘅書寫記錄
- 小朋友可以自己決定是否顯示家長留言
- 隨時可以退出家庭模式（進度保留）

## 5. 相關文案（補充）

**邀請文案**：
```
想同爸爸媽媽一齊探險嗎？
開啟家庭模式，進度可以一齊睇，
仲有專屬親子挑戰同分享卡片！
```

**親子完成提示**：
```

真係好溫暖呀～
```
