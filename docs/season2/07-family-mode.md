# 家庭模式（對齊「無帳號／無後端」）

Season 1 係 **localStorage 單機**。原稿邀請碼、雙裝置共同錢包會要求後端——列為待決定 **D4**。

## 建議先做：本機家長檢視（D4-A）

| 項目 | 說明 |
|------|------|
| 開啟 | 「我」頁 → 開啟家長檢視（可設簡單 PIN，存本機） |
| 進度 | 家長睇到完成日、溫習、骨頭、相簿進度（唯讀） |
| 鼓勵句 | 家長留一句短文字，小朋友首頁睇到 |
| 親子挑戰 | 清單提示（一齊讀三次、講例句）；打勾存本機；獎貼紙而非破 cap 骨頭 |
| 分享 | 用現有分享卡模板，家長自行截圖／分享 |

## 暫唔做（除非拍板 D4-B）

- 邀請連結、跨裝置即時同步  
- 雲端共同骨頭錢包  
- 真正「家長帳號／小朋友帳號」登入  

## 文案

**邀請（本機版）**：
```
想爸爸媽媽一齊睇進度嗎？
開啟家長檢視，可以睇寫咗幾多、留一句鼓勵。
（而家係同一部裝置，唔使另開帳號。）
```

**親子完成**：
```
今日親子探險打卡！
屋企人同你一齊為汪汪探險隊加油，
真係好溫暖呀～
```

## 私隱

- 預設資料唔上傳  
- 家長檢視唔好改寫小朋友筆畫紀錄  
- 可隨時關閉；進度保留
