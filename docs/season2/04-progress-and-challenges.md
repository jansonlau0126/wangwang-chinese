# 進度、挑戰文案（對齊 Season 1）

進度頁仍然係 **蜿蜒公園小路**（S1 已有）。第二季可以加階段路標／貼紙，唔好改成另一套完全唔同嘅地圖引擎（除非另開專案）。

## 1. 首次進入（已開 S2）

```
歡迎加入汪汪探險隊！
跟住地圖繼續行，寫字、攞骨頭、換狗狗相。
第二季會用故事帶你去城市、大自然、屋企同學校。
```

## 2. 日常進度（動態）

```
第二季：{X} / 60 日
骨頭：而家有 {B} 嚿（今日仲可以攞 {剩}/2）
相簿：去「狗狗」頁睇 x/7
而家階段：{階段名}
```

階段名建議：出發準備／城市探險／自然奇遇／家庭日常／學校同夢想。

## 3. 章節開放（取代「新品種狗登場」）

```
叮咚！探險日記更新喇！

「{章節名}」開放，
{狗名}有話想同你講。

去進度睇故事，
或者去狗狗頁換相、揀同伴啦！
```

## 4. 挑戰（輕度）

### 每週小挑戰（可選）
名稱：毛毛每週小挑戰  
內容：本週課堂日都有寫（唔使「完美演算法」都可以先做「有完成」）  
獎勵：建議用 **貼紙／動畫**（待決定 D2／D5），避免額外大額骨頭破 cap。

文案：
```
本週毛毛小挑戰開啟！
今個星期有寫字，就有小貼紙。
你做得到嘅，加油！
```

### 連寫（若 D5-A）
只獎唔罰。3／7／14 日可以有動畫或貼紙；**唔扣進度、唔鎖字**。

### 回憶挑戰
即 S1 已有嘅 **溫習**：搵弱字再寫；完成可喺每日 cap 內爭骨。
