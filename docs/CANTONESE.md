## 2. 多音字處理（小朋友版）

原則：**每字只教一個常用讀音 + 一個例詞**，例詞要用嗰個讀音。
1. 讀音取教育局字詞表首列粵音；同時檢查 rime 字表該讀音不是低比例讀音。
2. 例詞從教育局字詞表**第一學習階段（ks1）**詞語揀，生活化、兩字為主，並用該詞的教育局粵拼核對。
3. 其他讀音暫不顯示（資料保留欄位 `otherReadings`，供日後高年級擴充）。
4. 讀聲調易混（如 上 soeng5/soeng6、下 haa5/haa6）：例詞決定讀音，例如「上面 soeng6 min6」（第一期已由「上山」改為「上面」，單字同例詞同讀 soeng6）、「下巴 haa6 baa1」。資料內以「例詞粵拼」為準，避免單字讀音同例詞矛盾。

資料欄位建議：`{ char, jyutping, exampleWord, exampleJyutping, otherReadings[] }`。

## 3. 讀音方案（2026-10-06 定稿）

**產品決定**：只用裝置內建 `speechSynthesis` 嘅**粵語（香港）**聲；**唔寄送 mp3、唔錄音、唔用雲端 TTS**（亦唔要求用户開帳）。每個學習畫面**永遠顯示粵拼**（帶調號）同例詞粵拼，無聲都可以跟住讀。

### 點樣揀聲
- 等 `voiceschanged`（加短 timeout），再揀聲。
- 優先 `zh-HK`／`yue`／`yue-HK`／`zh-yue`／`zh-Hant-HK`，以及名稱含 Cantonese／粵語／廣東／Sin-ji／HiuGaai／HiuMaan／WanLung 等。
- **唔會靜默改用普通話**（`zh-CN`／`zh-TW`／`cmn` 等）。無粵語聲就唔播，並提示「呢部機未有廣東話聲，可以睇住拼音讀」；「我」頁有加聲簡要說明；🔊 掣會顯示靜音／刪除線狀態。

### 單字聲調（裝置 TTS 限制）
瀏覽器唔接受粵拼／音素輸入，單字常會讀錯調或錯讀。實作策略：

1. **先讀例詞**（語境帶出目標讀音，最穩）  
2. 短停頓後 **再讀單字**（方便跟讀）  
3. UI 粵拼永遠係準則；聽錯時以拼音為準  

慢速模式（🐢／雙撃）降低 `rate`。首次 `speak` 必須喺用户點撃入面觸發（照顧 iOS）。
