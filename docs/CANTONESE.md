## 2. 多音字處理（小朋友版）

原則：**每字只教一個常用讀音 + 一個例詞**，例詞要用嗰個讀音。
1. 讀音取教育局字詞表首列粵音；同時檢查 rime 字表該讀音不是低比例讀音。
2. 例詞從教育局字詞表**第一學習階段（ks1）**詞語揀，生活化、兩字為主，並用該詞的教育局粵拼核對。
3. 其他讀音暫不顯示（資料保留欄位 `otherReadings`，供日後高年級擴充）。
4. 讀聲調易混（如 上 soeng5/soeng6、下 haa5/haa6）：例詞決定讀音，例如「上面 soeng6 min6」（第一期已由「上山」改為「上面」，單字同例詞同讀 soeng6）、「下巴 haa6 baa1」。資料內以「例詞粵拼」為準，避免單字讀音同例詞矛盾。

資料欄位建議：`{ char, jyutping, exampleWord, exampleJyutping, otherReadings[] }`。

## 3. 讀音音效方案（2026-10-06 更新）

**產品決定**：唔用人手／作者麥克風錄音；亦唔要求用户自己去開雲端 TTS 帳號。  
**讀音方案：待定（免錄音）**——候選包括開源粵語 TTS 預生成、開放授權音節錄音、改良裝置 TTS 等；要可公開放進免費 web app、盡量少署名、最好支援粵拼指定讀音（單字聲調）。研究同試聽樣本喺 box 上進行，**唔提交大型模型權重／試聽檔入 git**。

| 方案 | 說明 | 現況 |
|------|------|------|
| **裝置 `speechSynthesis`** | App 而家用緊；優先 `zh-HK`／粵語聲 | **現行後備／預設**；無粵語聲就只顯示粵拼 |
| **預產靜態 mp3（免錄音）** | 檔名仍係 `assets/audio/U+XXXX.mp3`、`U+XXXX_word.mp3` + `data/audio-manifest.json` | **待選定具體引擎／音源同授權** 後先批量生成 |
| 商業雲 TTS（Azure 等） | 質素高、可 SSML | 用户唔想為呢個開帳；腳本 `npm run audio` 僅作可選工具，**非既定方案** |
| 人手錄音 | — | **不做** |

### 實作備註
- 單字易讀錯聲調 → 優先揀「可餵粵拼／音素」嘅方法；否則要逐個試聽。
- 生成任何可分發音檔前，必須核對該模型／錄音集嘅授權（可否商用、要唔要署名）。
- UI 音效（叮、解鎖）可用合成短音，唔等同讀音方案。
